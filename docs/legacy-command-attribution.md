# Legacy command attribution

The local JavaScript replacements preserve user-facing responses and command
patterns from these retired CoffeeScript packages. The original source and
licenses are linked below; included notices are in `legacy-command-licenses/`.

| Local initializer | Original package | License |
| --- | --- | --- |
| `legacy-bikeshed.js` | [hubot-bikeshed 1.3.0](https://github.com/hubot-scripts/hubot-bikeshed) | MIT |
| `legacy-darts.js` | [hubot-darts 1.0.4](https://github.com/hubot-scripts/hubot-darts) | MIT |
| `legacy-principles.js` | [hubot-principles 1.0.0](https://github.com/hubot-scripts/hubot-principles) | Do What You Want to Public License v3 |
| `legacy-thank-you.js` | [hubot-thank-you 0.0.3](https://github.com/hubot-scripts/hubot-thank-you) | MIT |

The diagnostics, help, and rules packages remain installed as npm packages and
are loaded from their JavaScript implementations. Their package licenses are
included by npm. No CoffeeScript package or runtime loader is needed.
